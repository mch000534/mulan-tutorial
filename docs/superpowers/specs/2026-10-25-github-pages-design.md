# GitHub Pages 教學網站發布

使用者希望簡單展示現有教學網站，已選擇新建 GitHub 倉庫。

保留現有 `site/` 版面、圖片、影片、提示詞與設計文件。使用公開倉庫
`mulan-tutorial`，透過 GitHub Actions 發布靜態檔案。根目錄入口轉往
`site/`，保留 `../assets/` 與 `../design/` 的相對路徑。

比較：直接發布完整專案最省設定，但會公開不必要的工作檔；搬移 `site/`
到根目錄需要改寫素材路徑。選擇 Actions 僅打包既有網站和相關素材，
保持原始檔案結構。網站不需要伺服器或額外前端框架。

驗證：檢查所有 HTML 相對連結、圖片、影片是否存在；確認單檔大小；
發布後確認 Actions 成功、公開首頁與素材可透過 HTTP 存取。
