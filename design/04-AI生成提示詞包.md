# 《雌雄》AI 生成提示詞包

版本：V1.1（樣式塊改為本文件第二節的 STYLE-A／B／C 單一來源，`scripts/build_jobs.py` 負責套用並去除重複描述；修正 4.9 天子與 4.10 敵軍的設定圖格式）
用途：角色設定圖、場景概念圖、45 顆鏡頭首幀、圖生影片（i2v）

> 16:9 版本不另寫提示詞：`scripts/build_jobs.py` 會將場景與鏡頭的 `vertical 9:16 composition` 改為 `horizontal 16:9 composition`，尺寸 1280×720，輸出到 `assets/generated/scenes_16x9/` 與 `shots_16x9/`。9:16 與 16:9 為獨立重生成，不是裁切；9:16 搭配普通話音軌，16:9 搭配粵語音軌，見 `03-臺詞與雙語版本.md`。

## 一、使用說明

### 工具分工

| 階段 | 建議工具類型 | 產出 |
|---|---|---|
| 角色設定圖 | Midjourney／Flux／Seedream／Nano Banana 類 | 三視圖、表情、手部細節 |
| 場景概念圖 | 同上，加 `--ar 9:16` | 10 張場景定調圖 |
| 每鏡首幀 | 圖生圖（reference／image prompt）＋局部重繪 | 45 張 1080×1920 |
| 動態 | **MiniMax H3**（原生立體聲音軌） | 每鏡 5–15 秒整秒素材，環境聲與音效一併生成 |
| 後期 | DaVinci／Premiere | 統一調色、剪輯、混音 |

> 版本迭代很快，**以你手上工具的最新版本為準**；本文件只鎖定「視覺描述」與「一致性方法」。

### 三條工作流鐵律

1. **先角色，後場景，最後合成首幀。** 不要用一句提示詞同時生成「人＋場景＋動作」，角色一定會走樣。
2. **每個角色只鎖一組參考圖。** 三視圖 + 一張眼神特寫 + 一張手部特寫，之後所有鏡頭都掛這組參考。
3. **首幀用合成，不用抽卡。** 場景板 + 角色板 → 合成 → 局部重繪光影 → 再進 i2v。這樣 45 顆鏡頭才會是同一個人。

## 三、一致性工作流（必讀）

1. **生成角色三視圖**（正面／側面／背面），背景用中性灰，光線用均勻柔光。
2. **挑一張「基準臉」**，記下 seed 與模型版本，存成 `ref/mulan_face.jpg`。
3. **生成手部特寫**（繭、疤、指甲），存成 `ref/mulan_hands.jpg`。
4. **生成場景板**（無人），存成 `plates/S01.jpg` … `S10.jpg`。
5. **合成首幀**：把角色放進場景板，用局部重繪統一光線方向與色溫。
6. **i2v**：只給 5–15 秒整秒的單一動作，運鏡寫在提示詞裡，不要讓模型自己編；原生音軌只要環境聲與音效，音樂與人聲留給後期。
7. **回檢**：每張首幀對照 `00-視覺聖經.md` 第七節的一致性清單。

## 七、45 顆鏡頭首幀提示詞

> 用法：先貼 STYLE-A，再貼該鏡描述，最後貼全域負面詞。
> 樣式塊由 `scripts/build_jobs.py` 自動套用：**S8／S9 的鏡頭用 STYLE-C，#4 另註 STYLE-B，其餘用 STYLE-A**；
> 描述與樣式重複的字眼（`cinematic`、`9:16`、`5th century`、`35mm` 等）會自動去重，不會貼兩次。
> 角色一律掛 `ref/mulan_X.jpg` 作為 reference；沒有參考圖時，把角色設定描述整段貼上。
> `i2v` 欄位是圖生影片的動作提示，只給一個動作，不要疊加。
> 提示詞格式含 **MiniMax H3 原生音軌**：`Audio: 環境聲, 音效, no music, no dialogue, no singing`。
> 本節的 i2v 行與 `02-分鏡表-靜態與動態.md` 第二十一節**逐字一致**，由 `scripts/shotlist.py` 在建置時檢查。

## 八、參數與解析度

| 工具 | 參數 |
|---|---|
| Midjourney | `--ar 9:16 --style raw --s 150 --q 2`（寫實類不要用 `--niji`） |
| Flux／SDXL | 768×1344 或 832×1472，之後升到 1080×1920 |
| 影片 | MiniMax H3：原生 24fps、5–15 秒整秒、原生立體聲；慢動作以提示詞 slow motion ＋ 後期變速 |
| 輸出 | 首幀 JPG（q90，4:4:4）；影片 ProRes 422 或 H.264 高位元率 |

## 九、常見失敗與修正

| 症狀 | 原因 | 修正 |
|---|---|---|
| 每張臉都不一樣 | 沒有掛參考圖 | 用 `ref/mulan_B_face.jpg` 做 character reference，並固定 seed |
| 甲片每鏡不同 | 文字描述太抽象 | 用道具圖當 image prompt，並在負面詞加 `different armor, fantasy armor` |
| 手變成六根指 | 模型弱項 | 手部特寫單獨生成，或後期修圖；不要用廣角拍手 |
| 畫面太「乾淨」 | 缺材質詞 | 加 `dirt, sweat, worn fabric, chipped edges, dust` |
| 自動美顏 | 預設審美 | 負面詞加 `smooth skin, beauty filter, makeup`，正向加 `visible pores, chapped lips` |
| 血太紅 | 模型預設 | 改成 `dried dark brown blood, matte, no fresh blood` |
| 光線方向不一致 | 合成時沒統一 | 每張首幀標註主光方向，局部重繪時加 `light from camera left` |
| 動作太複雜 | i2v 一次給太多 | 一顆鏡頭只給一個動作，運鏡與動作分開寫 |
| 出現文字 | 模型亂加 | 負面詞加 `text, watermark, calligraphy`（除非該鏡需要軍帖文字） |
| 敵人像某個現實民族 | 描述含文化元素 | 改用 `plain black iron mask, no cultural markings, no patterns` |
